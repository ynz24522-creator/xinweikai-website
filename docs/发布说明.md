## 三、日常更新流程

1. 改内容：产品与联系方式改 `assets/js/data.js`；界面文案改 `assets/js/i18n.js`；样式改 `assets/css/style.css`。
2. 若改了分类/型号数据，可在 `tools/` 目录执行 `python3 build.py` 重新生成页面与数据文件（也可直接改 `assets/js/data.js`，效果相同）。
3. 自检：`python3 tools/verify_site.py`（结构、死链、i18n、数据一致性）与 `python3 tools/js_test.py`（搜索、筛选、询价清单、双语）。
4. 提交并推送：

```bash
git add -A && git commit -m "说明这次改了什么" && git push
```

5. 若改了 CSS / JS，请把 `tools/build.py` 里的 `ASSET_VERSION` 改成新值后重新生成，避免访客浏览器用到 10 分钟内的旧缓存。当前版本：`20260912c`（加入产品插图与放大浮层那一次）。

## 三点五、产品插图（示意图）

- 939 个型号的插图由 `assets/js/part-art.js` 现场生成：类型决定形状、封装决定引脚与比例、大类决定主色，同一型号永远一致。
- 想给某个型号换成实拍图：把图片放进 `assets/img/parts/`，在 `assets/js/data.js` 该型号条目上加 `"img":"assets/img/parts/xxx.jpg"`，重新推送即可（建议 640×480、≤80KB）。
- 改形状或在列表里调整映射：编辑 `part-art.js` 顶部的 `TYPE_SHAPE`（123 个类型键）与 `SHAPES` 形状库，然后更新 `ASSET_VERSION`。
